# assets/

Project-owned files only: icons, shaders, fonts and other things this project
makes itself. **Never Mojang assets** (PLAN_v4 D8). Textures, `lang/` files,
sounds and music are read at runtime from the user's own `minecraft.jar` and
`resources/` directory; nothing of Mojang's is embedded in the binary or
committed to this repository.

Empty in Phase 0.
